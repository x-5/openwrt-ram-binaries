# OpenWrt RAM-Mode Pre-compressed Binaries

Pre-compressed (UPX) binaries optimized for OpenWrt routers with constrained RAM / Flash (e.g. Xiaomi CR8809, CMCC RD103).

- **NetBird**: `netbird_linux_armv6` (UPX compressed ~6.2MB)
- **DStatus Agent**: `dstatus-agent_linux_arm7` (UPX compressed ~2.6MB)
